# 기사 요약: 이미 사용된 기프티콘 중고 판매 사기

- 언론사: 소비자가 만드는 신문 (2021. 12. 30.)
- 출처: https://www.consumernews.co.kr/news/articleView.html?idxno=640062
- 비고: 저작권 보호를 위해 본문 대신 핵심 사실만 요약함

## 핵심 내용
- 이미 사용한 기프티콘(치킨·커피·편의점 등)을 중고 플랫폼에 올려 팔고, 계좌이체를 받은 뒤 연락을 끊는 수법이 있다.
- 같은 쿠폰을 여러 번 올려 피해자가 여럿 생기기도 한다.
- 플랫폼 밖(문자·카카오톡)으로 옮겨 안전결제 없이 거래할 때 피해가 많다.
- 개인 간 거래라 피해자가 직접 사기를 입증하고 경찰에 신고해야 한다.
- 챗봇 안내 시사점: '쿠폰·번호가 이미 사용됨'은 사기 의심으로 분류하고, 발행처에서 사용 내역을 확인해 증거로 남기도록 안내한다.
