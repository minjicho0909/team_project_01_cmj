# 결정사항

답변참고문서를 점검하고(2026-11-12, 독립 점검 에이전트 + 팀 질의응답) 정한 내용이다.
서버(api)·화면(public)을 만들 때 이 문서를 먼저 읽는다. 바꾸려면 팀 회의로 정하고 이 문서를 고친다.

## 1. 서버를 만들 때 지킬 것

| 번호 | 정한 것 | 이유 |
|---|---|---|
| S1 | **위기 표현(자살·자해)을 감지하면 검색 없이 고정 문구로 109를 가장 먼저 안내한다.** 조각은 근거 표시용으로만 쓴다 (Q2) | 기획서 필수 조건 "위기 놓침 0건"을 검색 결과에 맡길 수 없다 |
| S2 | **보이스피싱(인증번호·비밀번호 알려 줌, 링크 눌러 앱 설치)은 고정 문구로 "즉시 112 신고, 송금 은행에 지급정지 요청"을 안내한다** (Q19) | 시간이 급한 안내라 검색 실패가 치명적이다 |
| S3 | 서버가 읽는 경로는 **`docs/답변참고문서/청킹/*.md` 하나로 코드에 고정**한다. `vercel.json` 의 includeFiles 는 `docs/**` 그대로 둔다 (Q15) | `제외/` 의 조각도 `출처:` 로 시작해서, docs 아래를 통째로 읽으면 빼 둔 조각이 되살아난다 |
| S4 | **`…_문서정보` 조각은 검색 대상에서 뺀다.** 답 끝에 원문 주소를 보여 줄 때만 쓴다 (Q3) | 기관 이름·주소만 담겨 있어 알맹이 없이 검색에 먼저 뽑힌다 |
| S5 | 조각 1행(`출처:`)과 2행(`키워드:`)은 본문과 떼어 처리한다. **근거 표시는 「문서 이름 · 소제목」 모양으로 `#` 기호 없이** 보여 준다. 표 안의 `<br>` 은 화면에서 줄바꿈으로 바꾼다 (Q16) | 상담원이 원문의 어느 부분인지 바로 찾게 한다 |
| S6 | **AI가 안내하는 기관은 기획서 목록만 쓴다**: 경찰청(ECRM·경찰서), 거래 플랫폼, 전자문서·전자거래분쟁조정위원회, 대한법률구조공단, 온라인피해 365센터, (범위 밖) 예금보험공사·109·112. 소비자원·1372·소비자24·더치트·사이버캅은 조각에 있어도 "참고"로만 언급한다 (Q10) | 공식 출처 내용은 지우지 않으면서 기획서와 맞춘다 |
| S7 | AI는 **환급·배상 비율을 말하지 않는다.** 분쟁 안내는 "플랫폼 → 분쟁조정위원회"까지만 하고, 금액을 묻는 질문은 분쟁조정위원회로 안내한다 (Q12) | 길잡이는 "어디로"를 안내하고 "얼마"를 판정하지 않는다 |
| S8 | 이용자 입력은 **버튼 상황 진단으로 사기·착오송금 등을 먼저 가른 뒤** 검색한다 (Q14) | "송금했는데 물건이 안 와요"에 착오송금 조각이 먼저 나오는 것을 막는다 |
| S9 | **증거 정리표는 화면에 고정된 양식**으로 만들고, 항목마다 근거 문서를 적는다. 근거가 없는 항목은 공식 자료를 찾아 채운다 (Q8) | 피해자마다 양식이 달라지면 상담원이 받아 보기 어렵다 |

## 3. 새로 모을 자료

- 비실물: **기프티콘·모바일 상품권, 공연·스포츠 티켓.** 종이(지류) 상품권은 시제품에서 뺀다 (Q17)
- 증거 정리표 항목의 근거: 경찰 신고 때 준비할 것, 판매 글·대화 저장 등 (Q8)
- 모으는 방법: Claude가 기관·발행사 공식 누리집에서 후보를 찾아 목록을 보여 주고, 팀이 고른 것만 `원본/` 에 넣는다 (Q18)

## 4. 원칙

- **자료끼리 어긋나면 최신 공식 자료(기관 누리집)를 따른다.** 기획서와 다르면 기획서를 고친다. 공식 자료끼리 다르면 둘 다 두고, AI는 "기관에 확인하세요"라고 안내한다 (Q11)
- 기획서는 Claude가 **수정안만 보여 주고** 팀이 .md·.docx·.pdf 를 함께 고친다 (Q21)
